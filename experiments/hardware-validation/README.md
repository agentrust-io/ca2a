# Hardware validation runs

Repository-owned scripts and transcripts from live cA2A validation runs.

- `ca2a-attested-peer-azure-2026-07-27/` exercises an attested Azure peer.
- `ca2a-cross-tee-2026-07-27/` contains the SNP client, TDX peer, and captured transcript for the cross-TEE run.

Run the Python entry points from their respective directories in equivalent confidential-computing environments. Captured transcripts are regression evidence; new runs should be stored in a new dated directory rather than overwriting them.
